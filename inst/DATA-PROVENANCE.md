# Data provenance and validation scope

Reviewed 2026-10-03, revised 2026-10-08. Package maintainer: Manuel J. Sánchez-Franco.
This inventory records technical provenance. It does not assert that the MIT
license grants rights over third-party source material. The redistribution
basis for the derived numeric datasets and test fixtures is recorded below.
No source PDFs, page images or copied implementation code are distributed with
the package.

## Packaged datasets

All objects are generated by `data-raw/datasets.R` in the source repository.

| Objects | Origin and transformation | Redistribution record |
|---|---|---|
| `ratings_example`, `beta_binomial_example`, `metheringham_example`, `hofmans_accumulation_example`, `duplication_example`, `canex_example`, `bbd_reach_example`, `msad_example`, `csd_example`, `mbd_example` | Original illustrative inputs; vectors and matrices assembled into named argument lists. `csd_example` uses pairwise overlaps 0.07, 0.04 and 0.02. | Declared original package data; MIT package license. |

Every packaged dataset is original. Since 2026-10-08 the package no longer
distributes the inputs of published worked examples: the former objects
`csd_kim2005`, `msad_kim2005` and `mbd_cheong2007` were removed because the
basis for redistributing them (a license, an authorization, or a justification
that no authorization is needed) was not established. The comparisons with those
examples (Kim 1994 and 2005, Cheong 2007, Lee 1988, Danaher 1991) are
local-only tests of the maintainer (`tests/testthat/test-local-published-examples.R`,
not tracked by git and excluded from the archive), together with the two
published-plan tables below.

The two published-plan files (`cbd_published_plans.csv` and
`kim2005_appB_models.csv`) reproduce the complete numeric appendices of Kim
(2005) and Hong (1998). They are validation material only: no function, example
or vignette reads them. Since 2026-10-08 they are **local-only files of the
maintainer**: they are not tracked by git (see `.gitignore`), not published in
the repository and not distributed in the package archive (`.Rbuildignore`).
The tests that read them are skipped when the files are absent
(`skip_if_no_fixture()`), as happens in the built package, in the
continuous-integration workflow and in any clone of the repository. The
maintainer runs the complete suite locally (`testthat::test_local()`) with the
files present before each release. The files remain in earlier commits of the
public history. The statements of the documentation about the 80 two-vehicle
plans (agreement within 0.01 percentage points) describe those local runs.

Redistribution: the package archive distributes only original illustrative
datasets, formulas and algorithms. No dataset, input table or complete output
table of a published worked example is distributed in the archive or tracked in
the public repository from this revision on (earlier commits of the public
history still contain the former datasets and the two published-plan tables).
This file does quote, for documentation and attribution, a small number of
individual printed values and short result rows (for example the seven printed
cells of the Cheong 2007 example, the printed MSAD cells of Lee 1988 and
isolated values of Kim 1994 and 2005) next to the differences computed from
them; those are the only published numbers the archive contains. The comparisons
with published examples quoted in the documentation describe the maintainer's
local runs. No permission from the authors or their institutions is claimed,
no finding of infringement is made, and the package's MIT declaration does not
license third-party source material.

## Tolerances and unresolved differences

* Kim/Hong CBD and Kim CANEX/CSD: explicit maximum absolute error of 0.02
  percentage points per cell. Inputs are rounded to four decimal places,
  outputs to 0.01 percentage point; inferred duplications add uncertainty.
  This bound is an empirical acceptance threshold, not a proved propagation bound.
* Kim MSAD: the same 0.02 percentage-point bound for 39 plans. Plan 19 differs
  by about 0.099 percentage point with the common CANX-reconstructed duplication
  (0.0000623). A separate test reproduces all five printed MSAD cells after
  rounding to two decimals using random duplication (0.03 * 0.0205 = 0.000615);
  maximum error is below 0.005 percentage point. This identifies a matching
  alternative input, not why the source used it. The common fixture is unchanged;
  the former 0.11 acceptance bound for this discrepancy has been removed.
* Cheong MBD: the largest absolute difference between `calc_mbd()` and the
  printed seven-cell distribution of the three-vehicle example (Cheong 2007,
  p. 75; Cheong, Leckenby and Eakin 2011, Table 4) is 0.0020348568 in
  probability (0.20348568 percentage points), in the cell of three exposures.
  The regression test accepts differences below 0.0025; that threshold is
  above the real maximum, not an estimate of the error of the package. The
  rounding of one printed cell to three decimals is at most 0.0005, smaller
  than that maximum. The comparison cell by cell (all values are probabilities;
  multiply by 100 for percentage points; difference = computed - printed):

  | Contacts | Printed | Computed | Difference | Test bound |

  | 0 | 0.515 | 0.515527551 | +0.000527551 | 0.0025 |
  | 1 | 0.164 | 0.162110225 | -0.001889775 | 0.0025 |
  | 2 | 0.112 | 0.110745217 | -0.001254783 | 0.0025 |

  The printed intermediate tables contain arithmetic inconsistencies: a product
  printed as .024(.057) = .003 (it is .0014); a printed sum of Beta-Binomial
  parameters of 7.294 where the printed formula gives 7.543; .562 where it gives
  .5646; an exclusive-grid sum of 1.001 and a cell of .068 where
  inclusion-exclusion gives .067. They are a plausible explanation for some of
  the differences, and the published distribution may inherit them, but the
  full cause of the differences has not been established: the public tests do
  not include an independent implementation of the printed procedure, and
  rounding of the published values alone is not shown to be sufficient or to be
  excluded. Do not adjust parameters to force agreement. This is an
  approximate replication of one printed example, not independent predictive
  validation.
* Kim (1994) CBD example: the published zero cell is 0.5066. The CANEX formula
  printed by Kim, applied to her printed inputs, gives 0.5103 (the package
  0.5102), and varying the eight inputs within their rounding (+/-0.0005)
  cannot go below 0.5074. The printed value cannot be reproduced from the
  printed inputs. Page 139 (PDF page 157) contains verifiable errata: a
  probability of 0.0055 converted to 0.06% instead of 0.55%, and printed
  percentages that add to 99.54% although labelled 100. These errata do not by
  themselves establish the cause of the difference in the zero cell, so it is
  recorded as an unexplained discrepancy with the printed value; both values are
  recorded in tests. The packaged value is a reconstruction from the printed
  inputs, not the printed number.
* Lee MSAD (Lee 1988, pp. 81-93; order as given): source outputs are printed to

## Bibliographic verification

Hyo Gyoo Kim (2005) and Heejin Kim (1994), *A Conditional Beta Distribution
Model for Advertising Media Reach/Frequency Estimation*, are different authors.
Their titles, dates and University of Texas at Austin affiliation were checked
against the local source documents. Candidate handles 2152/1590 (Kim 2005) and
2152/3215 (Cheong 2007) returned HTTP 403 to programmatic requests. Opened in a
browser on 2026-10-08, https://hdl.handle.net/2152/1590 resolves to the item
"A canonical sequential aggregation media model" (Kim, Hyo Gyoo, 2005) and
https://hdl.handle.net/2152/3215 to "Multivariate beta binomial distribution
model as a web media exposure model" (Cheong, Yunjae, 2007), both in the
University of Texas at Austin repository. They are not listed in DESCRIPTION
because that repository blocks non-browser clients, so the URL check of
`R CMD check --as-cran` would report them as inaccessible. No repository record
for Kim (1994) appeared among the first results of a title search of that
repository; a stable identifier for it remains unverified.

Aldás Manzano (1998), *Modelos de determinación de la cobertura y la distribución
de contactos en la planificación de medios publicitarios impresos*, Universitat
de València, has the verified institutional handle
https://hdl.handle.net/10550/38471. The Hofmans, Agostini and Metheringham formula
checks use this source, not a claim to have inspected every original article.

The full text of Danaher (1992) has not been obtained. The publisher and the
author's university record confirm the conditional independence statement;
CBD implementation verification relies on the full Kim (1994) specification.
